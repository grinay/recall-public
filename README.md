# Recall

A passive macOS focus companion for ADHD. Everything runs on-device.

## Download

[Latest release →](https://github.com/grinay/recall-public/releases/latest)

Requires macOS 14+. Drag Recall.app to Applications, launch, grant
Screen Recording + Accessibility when prompted.

## Updates

Recall checks for updates automatically once a day. You can also
trigger a check from Settings → About → Check for Updates…
